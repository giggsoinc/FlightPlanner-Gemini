# Install via Gemini Gems (browser or app)

- Open Gemini in your browser (gemini.google.com) or the Gemini app. Sign in.
- Open the **side panel** (menu icon, top left).
- Click **Gems**, then **New Gem**.
- Name: `FlightPlanner`.
- Description: "Interview-first flight planner. Live fares only, top-3 table, ±3-day pricing."
- Open `skills/unified-flight-planner/SKILL.md` in this repo and copy everything below the `---` front matter.
- Paste it into the **Instructions** box.
- Click **Save**, then start a chat with the Gem.
- Say: "Plan a trip for me." It should interview you first.
- Turn on Google Flights/Hotels access in Gemini so prices are live.
