# Install via Gemini Gems

- Open the Gemini app and go to **Gems** > **New Gem**.
- Name it `FlightPlanner`.
- Open `skills/unified-flight-planner/SKILL.md` in this repo.
- Copy everything below the `---` front matter.
- Paste it into the Gem's **Instructions** box.
- Save the Gem.
- Start a chat and say: "Plan a trip for me."
- Expect the interview first, with no search until the goal is locked.
- Enable flight/hotel search extensions so prices are live.
- Without live tools, the Gem will say it cannot confirm prices.
